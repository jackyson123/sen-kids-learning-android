# SEN 兒童學習 — Android App

SEN 兒童學習係一個免費嘅廣東話兒童學習 app，專為有特殊學習需要嘅小朋友設計，有 18 個互動學習活動：認情緒、識字、數數、社交故事、冷靜角落、溝通圖卡、情緒日記、專注力訓練、生活自理、獎勵貼紙簿、語言仿說、安全教學、感覺統合、時間概念、睡眠故事、家長自訂內容、進度報告，仲有家長專區。

- 免費，唔收費，冇廣告
- 全廣東話，支援粵語、普通話、英文讀出
- 唔使開帳戶，資料只存喺手機，唔會上傳
- 網頁版：https://sen-kids-learning.vercel.app/

## 下載安裝

1. 去 [Actions](https://github.com/jackyson123/sen-kids-learning-android/actions) 下載最新嘅 debug APK（artifact 叫 `sen-kids-learning-debug-apk`）
2. 喺 Android 手機安裝 APK 就可以用

正式版會上架 Google Play，到時可以直接喺 Play Store 下載。

## 技術說明

呢個 Android app 係用 Trusted Web Activity（TWA）將網頁版包裝而成。開發同上架流程見 [docs/DEVELOPER.md](docs/DEVELOPER.md)。
